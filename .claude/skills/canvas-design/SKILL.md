# Canvas Design Skill

Create museum-quality visual art through design philosophy and expert craftsmanship.

## Workflow

### Step 1: Create Design Philosophy

Write a design philosophy as a markdown document (4-6 paragraphs) that articulates an aesthetic movement. The philosophy should:

- Name and describe a specific aesthetic movement or direction
- Reference art, design, or cultural influences
- Define the visual language: palette, texture, composition rules
- Establish constraints that drive creative decisions
- Include subtle conceptual references that enrich the work

The philosophy is the foundation — it guides every visual decision that follows.

### Step 2: Express Visually

Transform the philosophy into a visual artifact (PNG or PDF) using expert craftsmanship principles:

**Composition**
- Use the rule of thirds, golden ratio, or deliberate asymmetry
- Create visual hierarchy through scale, contrast, and placement
- Balance negative space with content areas
- Guide the viewer's eye through the composition

**Color**
- Build a cohesive palette (3-5 colors max for harmony)
- Use value contrast for readability and depth
- Consider color temperature and emotional associations
- Apply color strategically — not everywhere, but where it matters

**Typography**
- Choose typefaces that embody the design philosophy
- Create hierarchy through size, weight, and spacing
- Treat text as a visual element, not just content
- Respect letter-spacing, line-height, and measure

**Texture & Detail**
- Add depth through subtle textures, gradients, or patterns
- Use grain, noise, or halftone effects where appropriate
- Layer visual elements for dimensional richness
- Pay attention to edges, borders, and transitions

**Craftsmanship Standards**
- Every element must be intentional — no filler
- Pixel-perfect alignment and spacing
- Consistent visual language throughout
- The final piece should feel "meticulously crafted" and "the product of deep design expertise"

### Output Requirements

- Text should be minimal and integrated into the visual design
- The artwork should stand on its own without explanation
- Prioritize visual impact over information density
- Deliver as self-contained HTML that can be captured as PNG/PDF

### Quality Bar

Think of each output as if it were:
- A piece in a design museum exhibition
- A cover for a prestigious design publication
- A poster that someone would frame and hang

The subtle conceptual thread woven into the design should operate like "a jazz musician quoting another song" — intelligible to those familiar with the reference yet accessible to all viewers through pure visual beauty.
